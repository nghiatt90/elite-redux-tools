# Elite Redux Tools

Community tools for [Pokemon Elite Redux](https://reliccastle.com/games/450/), a Pokemon Essentials fangame.

## Planned tools

- **Damage calculator** — compute damage ranges accounting for Elite Redux's custom mechanics, movesets, and stat changes.
- **Pokedex** — searchable Pokedex reflecting Elite Redux's rebalanced stats, types, abilities, and movesets.
- **Save editor** — inspect and edit Elite Redux save files.
- **Build recommender** — suggest movesets/EV spreads/held items for a given Pokemon and role.

## Status

Early scaffolding. No tools implemented yet.
