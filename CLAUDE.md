# Elite Redux Tools

Tools for Pokemon Elite Redux (a Pokemon Essentials fangame with custom mechanics, stats, types, and movesets that diverge from vanilla Pokemon).

## Project scope

- Damage calculator
- Pokedex (Elite Redux data)
- Save editor
- Build recommender

## Notes

- No tech stack chosen yet — pick one when the first tool is scaffolded.
- Elite Redux game data (species/move/ability changes) is not vanilla Pokemon data — don't assume mainline values are correct; source from the game's actual data files/PBS when available.
